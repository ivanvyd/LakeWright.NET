# Adopters

Organizations that run LakeWright.NET, listed only with their consent. The list is empty until
someone asks to be on it. [ADR 0037](docs/decisions/0037-public-fold-criterion-and-nomination-bar.md)
counts these entries when deciding whether the project stays active.

## Add your organization

Open a pull request that adds a row. Name only what you are willing to have public.

| Organization | What it uses LakeWright for | Cloud | Since |
|---|---|---|---|

## Report privately

If you cannot be named, email the maintainer address listed on the
[@ivanvyd](https://github.com/ivanvyd) GitHub profile with `ADOPTER` in the subject. Say what you
use it for and on which cloud. The report is counted in
[`docs/adoption/signals.md`](docs/adoption/signals.md) without your name, and nothing else about it
is published.

## Report an acceptance run

If you ran the cross-tenant isolation check in your own workspace, open an issue with the output
and the cloud. It is recorded in the
[`docs/release-evidence`](docs/release-evidence) format and counted as an independent acceptance
report.
