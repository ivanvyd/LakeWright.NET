# 3.0.0 release evidence

Stable release completed on 2026-11-07. GitHub verifies the signatures on `v3.0.0-rc.1`
and `v3.0.0`; both tags resolve to `e3b5bfcafe9f73d841e2b30daff24349ee345540`.
The [candidate workflow](https://github.com/ivanvyd/LakeWright.NET/actions/runs/42364159721)
published the prerelease before the [stable workflow](https://github.com/ivanvyd/LakeWright.NET/actions/runs/42364885330)
published [v3.0.0](https://github.com/ivanvyd/LakeWright.NET/releases/tag/v3.0.0).
Both runs passed their build, non-live tests, package publication, provenance and public NuGet
availability gates.

All thirteen stable package versions were independently found in NuGet's public flat-container
indexes. Each downloaded package passed `dotnet nuget verify --all`, identified the release
commit and matched the attested build payload apart from NuGet's repository signature.
Provenance verification required the repository release workflow, exact source commit and
a GitHub-hosted runner. The release includes the packages and a CycloneDX SBOM.

Public `LakeWright.Tooling` 3.0.0 installed into a new tool directory and package cache.
Its `verify-floor` command checked the downloaded public Core, Databricks and Embedding
identities and hashes, restored into a fresh cache, and built and ran its canonical net8
consumer. The candidate passed the same check before stable promotion. Separate public-feed
consumers passed the membership, query and denied-tenant fixture on .NET 8 and .NET 10.

The major version records the admission transaction change described in
[ADR 0033](../decisions/0033-operation-admission-and-deletion-liveness.md).
No live Databricks workspace execution or Azure application deployment was performed.
