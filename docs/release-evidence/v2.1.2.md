# 2.1.2 release evidence

Stable release completed on 2026-11-07.

GitHub verifies the signatures on `v2.1.2-rc.1` and `v2.1.2`. Both tags resolve to
`45b86dc80cafa3fedfd9ccbff2ea3968a9956d5f`. The
[candidate workflow](https://github.com/ivanvyd/LakeWright.NET/actions/runs/42340177736)
published [v2.1.2-rc.1](https://github.com/ivanvyd/LakeWright.NET/releases/tag/v2.1.2-rc.1).
The [stable workflow](https://github.com/ivanvyd/LakeWright.NET/actions/runs/42344002557)
passed its build, non-live tests, package publication, provenance attestation, and public NuGet
availability checks before publishing [v2.1.2](https://github.com/ivanvyd/LakeWright.NET/releases/tag/v2.1.2).

Independent checks found all thirteen intended package versions in NuGet's public flat-container
indexes. Each downloaded package passed `dotnet nuget verify --all`, identified the release commit,
and matched its attested build payload, excluding the repository signature added by NuGet.
Provenance verification required this repository's release workflow, the exact source commit,
and a GitHub-hosted runner. The GitHub release includes the packages and a CycloneDX SBOM.

`LakeWright.Tooling` 2.1.2 installed from nuget.org into a new tool directory and package cache.
Its `verify-floor` command restored the downloaded public Core, Databricks, and Embedding packages
into another fresh cache, checked their identities and hashes, and built and ran the canonical
net8 consumer fixture. The candidate passed the same consumer check before stable promotion.

This verifies package publication and offline consumer behavior. No live Databricks workspace
execution or Azure application deployment was performed for this release.
