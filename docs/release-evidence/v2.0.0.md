# 2.0.0 release evidence

Stable release completed on 2026-09-02.

The signed release-candidate and stable tags point at the same audited commit. The
[release-candidate workflow](https://github.com/ivanvyd/LakeWright.NET/actions/runs/33669553939)
published `v2.0.0-rc.1`; the
[stable release workflow](https://github.com/ivanvyd/LakeWright.NET/actions/runs/33670968920)
then published [v2.0.0](https://github.com/ivanvyd/LakeWright.NET/releases/tag/v2.0.0). Each
workflow completed its signed-tag, confidentiality, build, test, package-order, SBOM, provenance,
and public NuGet-index checks before creating its GitHub release.

The stable release published all thirteen package surfaces: AI, AspNetCore, Caching.Distributed,
Caching.Redis, Conversations, Core, Databricks, Databricks.RawData, Embedding, Embedding.Ops,
HealthChecks, Multitenancy, and Tooling. Publication order is derived from each packed package's
internal NuGet dependencies, and CI rejects a candidate if that order omits any packed primary
package.

After publication, a clean net8 consumer restored the public Embedding and Databricks 2.0.0
packages from nuget.org and printed `OK`. The public `LakeWright.Tooling` 2.0.0 package also
installed and inspected the safe dashboard fixture successfully. The published consumer path uses
membership-resolved schema-per-tenant catalog/schema delivery; generic shared-schema SQL is
deliberately unsupported.

The merged-source CI completed the confidentiality preflight, build, tenant-isolation,
package-consumer, documentation, bundle-schema, and general test jobs:
[CI 33668717431](https://github.com/ivanvyd/LakeWright.NET/actions/runs/33668717431). The matching
[security run 33668668381](https://github.com/ivanvyd/LakeWright.NET/actions/runs/33668668381)
also completed successfully.

This evidence records package and automated validation. It does not claim a live Databricks
workspace execution or a named downstream adopter.
