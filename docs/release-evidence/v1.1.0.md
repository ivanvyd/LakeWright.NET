# 1.1.0 release evidence

Pre-publication run on 2026-09-01 against merged main commit
`c5ffa094d2b438416f9510abb69f552d3e0e3033`. Publication evidence is appended after the immutable
tag workflow completes.

## Scope

The release adds opt-in tenant-safe Databricks billing attribution and a privileged, non-packable
audit-partition maintenance tool. It also contains the queued dependency and pinned-action updates
from pull requests #78, #79, #80 and #82. Every open feature and Dependabot pull request was
resolved before regression; `gh pr list --state open` returned an empty list.

## Repository gates

```text
dotnet restore LakeWright.slnx --locked-mode
dotnet restore scripts/load/Lakewright.LoadHarness/Lakewright.LoadHarness.csproj --locked-mode
dotnet build LakeWright.slnx -c Release --no-restore
dotnet build scripts/load/Lakewright.LoadHarness/Lakewright.LoadHarness.csproj -c Release --no-restore
dotnet format LakeWright.slnx --no-restore --verify-no-changes
dotnet list LakeWright.slnx package --vulnerable --include-transitive
dotnet list scripts/load/Lakewright.LoadHarness/Lakewright.LoadHarness.csproj package --vulnerable --include-transitive
dotnet list tools/LakeWright.DatabaseMaintenance/LakeWright.DatabaseMaintenance.csproj package --vulnerable --include-transitive
dotnet test LakeWright.slnx --no-build --no-restore -c Release --filter "Category!=Live" --logger trx --collect:"XPlat Code Coverage"
dotnet test LakeWright.slnx --no-build --no-restore -c Release --filter "Category=TenantIsolation" --logger trx
```

Result: locked restores passed. Both Release builds completed with zero warnings/errors. Formatting
passed. Every project reported no vulnerable direct or transitive package. The non-live suite
passed 251/251 and the independently gated tenant-isolation filter passed 209/209. TRX and
Cobertura artifacts were retained under the run's ignored `.git/codex-artifacts` directory.

The documentation scripts initially read ignored personal `local/` notes, making local results
depend on files outside the repository. They now enumerate tracked plus non-ignored new Markdown
files. With the release evidence present, 113 relative links/images resolved and no stale claims
were found. No
personal file was edited.

The audit partition subset passed 21/21 against PostgreSQL 17. Its negative cases include corrupt
lifecycle state, missing range index or registry primary key, disabled and replica-only identity
triggers, and loss of `SECURITY DEFINER`. The positive lifecycle includes populated copy/compare,
UTC month arithmetic across DST, bounded sparse history, ACL restoration, a non-superuser owner
with FORCE RLS-hidden rows, rollback, cleanup/remigration and finalize. CLI help exposed only
`migrate`, `validate`, `finalize`, `rollback` and `maintain` and executed no DDL.
