# Raw research notes

These are working notes from the research that produced the plan and the decision records. They are
kept because the reasoning behind a decision is more useful than the decision, and because a reader
who disagrees should be able to check the evidence rather than take the conclusion on trust.

**Read them as evidence, not as documentation.** They carry confidence labels:

- **VERIFIED** — read on a live page on 2026-07-31, with the URL and the page's own last-updated date.
- **RECALLED** — from model training memory, unconfirmed. A lead, not a fact.
- **COULD NOT DETERMINE** — searched, no authoritative source found. Recorded rather than guessed.

Several findings are Public Preview features and will move. Where a note and a decision record
disagree, the decision record is current and the note is a snapshot.

One correction is preserved in `06-bundles.md` rather than edited out: an intermediate pass wrongly
attributed the Declarative Automation Bundles rename to a CLI version. It is recorded so nobody
re-derives it.
